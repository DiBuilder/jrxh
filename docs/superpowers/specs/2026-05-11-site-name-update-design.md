# 网站名称更新设计文档

## 概述

将网站名称从"吉祥选号"更新为"吉日选号工具"，以更准确地反映网站的核心功能——基于黄道吉日的彩票选号工具。

## 目标

1. 更新所有页面标题、描述和元数据中的网站名称
2. 优化SEO关键词，提升搜索引擎可见性
3. 保持现有功能和设计不变

## 修改范围

### 1. 核心配置文件

**文件：`app/layout.jsx`**
- 修改 `SITE_NAME` 常量：`'吉祥选号'` → `'吉日选号工具'`
- 更新 `keywords` 数组：
  - 将 `'吉祥选号'` 改为 `'吉日选号工具'`
  - 添加：`'吉日选号'`, `'黄道吉日选号'`, `'吉日选号器'`
- 所有使用 `SITE_NAME` 的地方（标题、描述、OpenGraph等）会自动更新

### 2. 页面标题

**文件：`app/bazi/page.jsx`**
- `title: '生辰本命选号 | 吉祥选号'` → `title: '生辰本命选号 | 吉日选号工具'`

**文件：`app/huangdao/page.jsx`**
- `title: '今日黄道选号 | 吉祥选号'` → `title: '今日黄道选号 | 吉日选号工具'`

### 3. 项目文档

**文件：`README.md`**
- 标题：`# 吉祥选号 (Jixiang Xuanhao)` → `# 吉日选号工具 (Jiri Xuanhao Gongju)`

**文件：`CLAUDE.md`**
- 项目概述：`"吉祥选号"` → `"吉日选号工具"`

### 4. 不修改的部分

- `components/Logo.jsx` - Logo文字保持"吉祥"不变
- 其他代码逻辑、样式和功能
