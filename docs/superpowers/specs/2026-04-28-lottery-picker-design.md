# 命理彩票选号 — 首页设计

## 概述

一个基于农历/生辰推算的彩票选号工具。中国风视觉（深红底 + 金色文字），Next.js 单页应用，纯客户端渲染。

## 技术栈

- Next.js App Router（预留 SSR 扩展空间，当前全部 `'use client'`）
- React 19
- lunar-javascript（农历干支、四柱、纳音）
- 纯 CSS（CSS 变量驱动主题色）

## 页面结构

单页，`app/page.jsx` 作为 `'use client'` 主容器。

```
┌──────────────────────────────┐
│   TopTabs                    │
│   [今日黄道选号] [生辰本命选号]   │
├──────────────────────────────┤
│   号码展示区                   │
│   红球 ×6  + 蓝球 ×1          │
│   （大乐透时：前区 ×5 + 后区 ×2） │
│                              │
│   解读文案                     │
│   （生辰模式含五行分析）         │
│   （生辰模式显示表单：           │
│    年月日时选择器 + 生成按钮）    │
├──────────────────────────────┤
│   [双色球] [大乐透]   [复制号码] │
└──────────────────────────────┘
```

## 数据流

### 初始加载
页面打开 → 默认「今日黄道」+「双色球」→ 用当日农历干支生成种子 → 随机选号 → 展示号码 + 解读

### 切换 Tab
- 今日黄道 → 今日模式：直接显示号码（每次切换到该 Tab 重新用当天种子生成）
- 生辰本命 → 显示表单，用户填入年月日时后点击「生成」→ 计算

### 生辰本命选号流程
用户输入年月日时 → 点击生成 →
1. lunar 转农历 → 排四柱（年柱、月柱、日柱、时柱天干地支）
2. 统计四柱中八个字的五行出现次数（甲乙木、丙丁火、戊己土、庚辛金、壬癸水）
3. 找出出现次数最少的五行作为「缺」
4. 按河图数映射（水=1/6, 火=2/7, 木=3/8, 金=4/9, 土=5/0）
5. 从缺的五行对应尾号号码池中优先随机选取
6. 红球按双色球/大乐透规则，蓝球/后区取日柱纳音五行对应数字
7. 生成一句解读

### 切换彩票种类
双色球 ↔ 大乐透 → 按新规则重新生成当前模式下的号码

### 复制号码
拼接号码为文案字符串 → `navigator.clipboard.writeText`

## 选号算法

### 今日黄道模式
- 获取今日农历日干支序号 + 吉时地支序号
- 组合作为随机种子，生成伪随机序列
- 红球从 33（双色球）或 35（大乐透）中不重复选 n 个
- 蓝球从 16（双色球）或 12（大乐透）中选 n 个

### 生辰本命模式
- 五行统计：四柱八个字 → 天干五行 + 地支五行
- 缺五行：出现次数最少的五行（平局取第一个）
- 号码池：缺的五行对应尾数（如缺金→尾数4/9的号码优先）
- 红球优先从缺五行号码池随机选取，不足时从全池补齐
- 蓝球/后区：日柱纳音五行对应的数字

## 五行数字映射（河图数）

| 五行 | 尾数 |
|------|------|
| 水   | 1, 6 |
| 火   | 2, 7 |
| 木   | 3, 8 |
| 金   | 4, 9 |
| 土   | 5, 0 |

## 彩票规则

| 类型   | 主区（红/前）      | 副区（蓝/后）      |
|--------|-------------------|-------------------|
| 双色球 | 1-33 选 6 不重复   | 1-16 选 1         |
| 大乐透 | 1-35 选 5 不重复   | 1-12 选 2 不重复  |

## 视觉风格

- 背景色：深红 `#8B0000`，渐变到稍亮暗红
- 文字色：金色 `#DAA520` / `#FFD700`
- 中文字体：`"STSong", "SimSun", "Noto Serif SC", serif`
- 球体：深红底 + 金色边框圆形 + 金色数字，直径约 48-56px
- 按钮：金色边框 + 深红底 + 金色文字，激活态金色填充
- 通过 CSS 变量管理主题色

## 边界情况

- 生辰表单未完整填入时「生成」按钮禁用
- 复制号码失败时静默忽略（某些浏览器/非 HTTPS 下 clipboard API 不可用）
- 五行统计平局时取第一个出现的最少五行
- 缺五行号码池不足以填满时从全池随机补齐
- 大乐透后区 2 个球与双色球 1 个球的蓝球展示差异
